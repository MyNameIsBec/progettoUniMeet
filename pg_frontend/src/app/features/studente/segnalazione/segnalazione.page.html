Cosa puoi segnalare?
Problemi con prenotazioni

Slot non visibili, errori di conferma o annullamento.

Notifiche e reminder

Avvisi non ricevuti o informazioni non aggiornate.

Documenti caricati

Errori nel caricamento o file non associati.

Dati profilo

Problemi con email, matricola o corso di studi.
Informazioni importanti
  • Le segnalazioni vengono lette dal team UniMeet.
  • Riceverai una risposta nella sezione notifiche.
  • Allega screenshot se visualizzi messaggi di errore.
